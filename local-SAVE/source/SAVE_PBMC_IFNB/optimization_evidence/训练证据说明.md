# 正式训练协议与证据

状态：B/R 五 seed 正式独立训练、独立重载与汇总均已完成；不代表最终交付通过。

初始正式种子为 17、29、43；触发事先追加规则后，最终共同 seed 集为 17、29、43、71、97。Baseline 为修复共同预处理/评分问题后的官方默认模型与 200 epoch 训练；Reference 使用完全相同的训练配方，每个 seed 重新初始化与训练，仅改变推理为观测控制表达加共享潜变量条件解码差，最后保证非负。

训练集 21,336 个细胞，2,000 个 HVG 仅由训练集拟合。训练集拟合 MaxAbsScaler，控制输入不能受目标刺激表达影响。主指标为原始 log1p 表达尺度上的逐基因均值 MSE，逐 seed 后取全部声明种子的算术均值。诊断为正确方向的 R² 与 PCC。U=0 是 MSE 数学下界，B 使用正式 Baseline 全 seed 均值；不把 Reference 当作上限。

若 Baseline 样本标准差/均值 > 0.10，或增益达到 3σ 但低于 5σ，事先声明追加 71、97 到双方共同 seed 集并完整保留已有结果。不同 seed 是独立训练，不是一个 checkpoint 的重复评估。

每轮 result.json 与 run.log 保留原始数值、训练设置、方法/依赖哈希与执行信息；model/ 保存真实权重、SHA256、大小、来源、artifact.json 与独立进程 reload.log。权重使用 weights_only 状态字典重载，逐指标误差不得超过 1e-8。

训练资源为实际授权的单张 A100-PCIE-40GB、4 CPU 线程，每轮 900 秒硬时限。每次主控作业先非阻塞取得既有两个共享锁并验证 GPU UUID/空闲显存，未停止其他任务或删除锁。专家独立执行不等于 Actor 沙箱或正式模型轨迹。
