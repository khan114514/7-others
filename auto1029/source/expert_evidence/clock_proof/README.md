# 独立双轨迹有效时段核算

本目录提供原始执行记录的时钟、状态和模型路由字段投影，以及可逐段复算的保守有效时长。只使用已经发生的指定模型工作及其提交的 GPU 实验；新增整理工作、排队、安装、基础设施失败、重试退避和无法确认的 CLI 尾段不计入。

| 独立轨迹 | 历史账本声明总量（秒） | 保守可复算下界（秒） | 下界（小时） |
| --- | ---: | ---: | ---: |
| gpt-6.1-sol / high | 40553.85330891609 | 36749.336764097214 | 10.208149101138115 |
| doubao-seed-2-1-turbo-260628 / high | 43548.57783436775 | 41497.01806259155 | 11.526949461830986 |

`trajectory_codex.json` 与 `trajectory_seed.json` 的 `metadata.duration_seconds` 是历史总量、也是 collector 的时长候选上界。实际可证明有效时长取本表保守下界，均不大于对应候选；两条轨迹分别核算，互不相加。历史账本、执行记录、轨迹轮次与科学数值均保留。

逐段从 `clock-source-projections.json` 的 `roles[].intervals` 查看实际原件 SHA、CLI 起止、原始事件时间/类型、成功和失败的请求回执、实际 GPU 起止/时钟偏移/传输不确定性，以及原执行时段上限。命令等待类型的布尔投影有明确推导规则；不以未提供的全文替代真实记录。CLI 与 GPU 取并集，重叠不重复计时。GPU 起止按传输不确定性收缩，并扣除等待共享 GPU 的时段。

五条缺少原始 CLI 日志的早期时段整个计为零：GPT 的 b04522d98c8042d0878790322847a652、7f6c54bf115c47cb9819f4d8cc2cfe9c、e6547da9845a443ba7850f5ca25ad6c4；Seed 的 b04522d98c8042d0878790322847a652、269f3e89020e41c2b25f8d19c07530dc。不补造日志，不用容器在线时长替代。另有两条早期 CLI 比旧声明分别少计 0.17042779922485352 秒（GPT74a7e7ef）和 0.8557319641113281 秒（Seed52c2a3a6）。

原 GPT2151 执行记录为 2538.662753343582 秒，后续闭合记录为 4694.224331140518 秒。原 Seedff8729 执行记录为 2164.689999818802 秒，后续闭合记录为 3430.8571197986603 秒。两种原件均完整保留、职责清晰；本保守核算再次与原 execution 的 included_intervals 相交，所以所有后补完成时段均排除。主控事后查询耗时始终计零。其它闭合核算仅用于保留实际 API 失败排除，不增加原 execution 时段。

`conservative-clock-result.json` 列出每条保守 included/excluded 区间、失败/退避、未确认尾段及排队时间，跨整条轨迹再合并取并集。`clock-arithmetic.source.txt` 是原主控纯核算函数的源码摘录；`clock-verifier.source.txt` 提供完整只读计算逻辑，只读本目录 JSON，不导入题目实现、不发模型请求、不运行评分或容器。这里的算术验证不替代独立语义审查。

投影范围：所有事件的时刻、类型和 item 标识保留；每条实际 provider 路由的请求/完成时刻、模型/HIGH、HTTP/完成状态保留；GPU 每个 job 的最早提交观察及最晚回执完整保留相关时钟字段，中间轮询行明确省略，原总行数和入选行序号可核对。原始命令、输出、提示、上游地址、provider 响应体和 GPU 科学评分嵌套字段不复制到本时钟投影，原数值不修改。私有原件逐件 SHA 保留；公开活动节选与原科学证据仍分别按各自职责提供。
