本目录保存真实非训练推理证据，路径以三目录提交包根目录为基准。全部正式 evaluation_seed 为17、29、43、71、101；不是五次模型训练，不创建空model目录。

baseline_runs/method.py 为普通AR空提议；reference_runs/method.py 为独立结构前缀提议。各seed的result.json记录冻结协议、源码/依赖哈希、真实执行信息、指标和质量门，per-sample.jsonl保留方法与同批校准的原始输出及计数。comparison_summary.json使用全部五组重新计算样本标准差和归一化改善。

所有seed来自一次实际GPU进程；三种策略通过各自隔离执行器执行，固定冻结目标模型不重复训练。每个seed的run.log都是该进程完整、未经编辑的stdout/stderr，字节一致；并未伪装成十个独立进程的日志。共享进程时间确有回执，逐seed耗时和峰值显存未单独记录，明确填null。命令中的部署目录仅替换为环境变量引用，原始回执留在私有审计档案。

v1墙钟锚点因实测GPU速度漂移而停止作为最终依据，原记录仍保留在私有档案。v2使用同批交错AR校准，数学下界U=0未移动，质量与采样协议未放宽。本目录不包含模型轨迹、Hidden资产、凭据或官方平台验收结论。完整Native NOP/Reference评分、双轨十小时、最终复跑和稳定性属于仍待完成的独立门槛。
