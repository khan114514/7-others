# Public evaluation implementation and asset access

These are byte-identical public source copies used by the trusted GPU backend. They are copied into the CPU Agent image by the existing `COPY public_eval` instruction, for inspection. They do not replace or add imports to the runtime client, bootstrap, trainer, or evaluator. The operational Public/Dev command remains `bash /workspace/environment/public_eval/solve.sh`; it runs the frozen backend and returns real raw FID under evaluation seed 0. This CPU image does not provide a local GPU evaluation service.

## Call and data flow

`engine/framework/generate_pairs.py` and `teacher_filter.py` generate teacher targets. `train_student.py` uses the fixed LPIPS plus token CE training objective. `vendor/var/sample.py` reloads the resulting EMA and generates 50000 images with the published single-step mixed output head. `engine/ram_png_entry.py` intercepts exact torchvision PNG bytes in RAM without changing PNG encoding, lexicographic ordering, RGB decoding, `ToTensor`, Inception features, reference statistics, or Frechet calculation. It calls `vendor/var/evaluation/fid_score.py`: Inception pool3 dimension 2048, batches 256, real statistics versus generated mean/covariance. The generation batch size is 8. All quality checks remain in the trusted backend. `engine/scoring.py` documents the shared untrimmed affine formula; actual private calibration values and policy are not included.

`vendor/var/models/` and `vendor/var/utils/` provide sampler dependencies. `engine/framework/` contains the fixed public teacher/training stages; `method_proxy.py`, `method_worker.py`, `worker_guard.py`, and `method_contract.py` describe the submitted method boundary. `config.py` is a source interface only; no deployment configuration or private host path is provided. `requirements.txt` records public Python dependencies; actual backend also uses PyTorch 2.5.1 and torchvision 0.20.1 with CUDA.

## Public assets

`assets.json` gives downloadable public URLs, exact byte sizes, and SHA-256 for the pretrained initialization, teacher, VAE, ImageNet-256 FID reference statistics, Inception, and AlexNet. These public data and weights are available to the Agent through its allowed public network, and are independently verified on the trusted GPU backend. They are not private test samples. No ImageNet original training set is required by this task: teacher pairs are generated by the public fixed stages. Numeric private evaluation seeds, private anchor values, private receipts, credentials and Reference methods are not part of these copies.

To retrieve assets for inspection, download each URL into a local directory preserving its `file` path, then verify the listed bytes and SHA-256 before use. Do not edit these read-only reference sources; the submission remains only `/workspace/solution/method.py`. `source-copies.json` links every copy to its current frozen original bytes. This source bundle is passive documentation; CPU-local import is not a supported scoring command.
