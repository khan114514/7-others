## 优化面

以固定正确性的多头注意力检索算子为输入输出合同，开放 attention 函数的算法和 CPU 张量实现。输入是 x、三个线性映射及 alpha/beta；控制参数由评分器提供。候选可以实现数学重排、分块、布局优化和按形状分支，而不是仅搜索控制参数。正式评分不含训练、COCO 图像生成或任何外部模型下载。

## Baseline 与 Reference

Starter/正式 Baseline 是正确直接实现：计算 q/k、原始及扰动 softmax，在投影前完整通道空间检索、混合和范数重缩放，然后进行 value 投影。主评分零点 B 来自该未修改 Starter 的全部正式 seed 聚合结果，没有另设弱锚点。与公开处理器三个配置的小规模对照最大误差约 3.1e-7，证据在 prerequisite_evidence/upstream-parity.json。它保留正确的完整通道范数，没有故障注入或故意减少计算预算。

Reference 针对 L 相对 C 较小时计算 G=XX^T，用 ||PX||^2=diag(PGP^T) 精确恢复缩放因子，同时利用线性映射与检索的结合律减少完整通道中间张量；其他形状回退直接计算，alpha=1 使用等价简化路径。数值误差必须满足题面固定 allclose 门。交接的窄投影近似处理器不是此题的正式 Reference。
