本题是非训练数值推理。没有 optimizer updates、学习曲线、训练 checkpoint 或训练重载分数，相关字段为 NOT_APPLICABLE，不以空文件冒充证据。

Baseline 与 Reference 各五个 seed，每 seed 六个真实案例、每例九次独立新进程，共 540 次实际求解与保真检查。每个 seed 保存 result.json、measurement.json 和原始 run.log。固定输入、目标、依赖、资源和观察器相同；正式运行串行。完整数值、n−1 标准差、三倍 Baseline 标准差检验及 B/R/U 公式见 comparison_summary.json。

B101 有一次与短诊断重叠的试跑，被明确排除；正式 B101 是其后的串行重跑。失败或较差尝试不混入统计，原记录保留。共同修复、缓存与计时边界修正发生在正式运行前，不计作 Reference 独有收益。

可信父观察器在 import/input 完成后的随机 READY/GO 开始计时，到数值写出后的随机 DONE 标记结束，包含方法计算和输出传输，排除 Python teardown。逐次结果可从 measurement.json 和 run.log 重算。Public/Dev 与隐藏 verifier 的 Baseline 因输入规模不同分别实测；隐藏未用于 Reference 选择。
