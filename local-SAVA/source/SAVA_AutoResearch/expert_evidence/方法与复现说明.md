# SAVA 方法、真实复现与任务边界

论文为 [SAVA: Scalable Learning-Agnostic Data Valuation](https://proceedings.iclr.cc/paper_files/paper/2025/hash/137101016144540ed3191dc2b02f09a5-Abstract-Conference.html)，ICLR 2025；[官方代码](https://github.com/skezle/sava) 固定于提交 `7efc8a20cab9898d56fcf32d4f57ae55589152c9`。专家制作阶段读取完整正文与附录。

## 官方运行与共同修复

未改官方算法的 smoke 用真实 Toronto CIFAR-10、官方 checkpoint 和原始入口完成。其收敛警告没有隐藏。诊断发现 batch 两侧总质量不等，以及 coupling 未传 feature_cost、与 potential 使用不同成本两项上游问题。修复在正式 B/R 之前共同使用，不计入 Reference 独有收益。原 batch 列边缘残差约 1，归一化后约 1.11e-16；同一真实样本上两种成本最大差为 21157.9883。失败与警告记录均保留。

官方 checkpoint SHA-256 为 `953a618a0a229240bcd29f67809f68432861dd209df8fc08d0041b4817444e2f`。其 PreActResNet 训练配方缺少来源证据；仓库普通 ResNet18 训练脚本不能证明该权重的训练历史。本题对相同固定特征的数值算子评分，不声称冻结 encoder 对新图像的泛化性能。

Toronto CIFAR 测试像素和标签与 uoft-cs/cifar10 测试集逐项一致；训练内容多重集一致但顺序不同，正式任务没有使用训练图像。共同特征缓存与修复后官方小样例的 Spearman 为 0.9999842641，最大相对差 0.00513887785，故只声明高度排序一致，不声明逐位等价。

## 最终问题及范围

任务评测固定输入上的分层传输估值数值保真与求解时间，保留标签条件 OT 几何、点 potentials、batch coupling、校准及汇总。canonical 明确继承官方 practical 正则约定：potential 绝对 eps=0.1，样本 coupling 归一化成本 reg=0.1，batch reg=0.01；这不是统一熵参数下严格理论 OT 的等价实现。每例每次调用要求 NRMS≤0.01、Spearman≥0.999、最高四分之一集合重叠≥0.98。

仅用 corruption detection recall 的早期公开 pilot 弱于冻结分类器 NLL 和 kNN disagreement，故未将其作为正式质量锚点或宣称检测优势。任务在正式运行前转为数值算子的 fidelity/效率问题。噪声检测仅保留为诊断，不混入正式 B/R。

所有输入为共同预提取的 10 维 logits，无训练或微调。reference=2000，Dev=3000，Hidden=5000，图像身份互不相交。Dev seeds=101/202/303/404/505；Hidden seeds=601/702/803/904/1005。每 seed 六例覆盖 uniform/asymmetric 标签噪声、三个强度 Gaussian 和 mixed。两侧均 2 CPU、2048 MiB、无 GPU。每次方法测量包括 value 的全部计算与输出传输，排除共同 import/input 和 Python 退出；每例九个新进程取中位数，每 seed 六例均值，再取五 seed 均值。

协议在正式运行前预注册，SHA-256 为 `032b884e3ba39ec42ced7b7eaba3ccb57220b549f0305b9978453ce0d56ce1f5`。首次 Docker 观察器误计 teardown 的问题在正式运行前修复，没有放宽门槛或改变 seeds/U。首个 B101 试跑与专家短诊断重叠，明确排除并串行重跑；正式十次运行串行完成。

Baseline 均值 0.521494621098 秒，n−1 样本标准差 0.006102814476；Reference 均值 0.380399683567 秒，标准差 0.003247775168。提升 27.055876%，为 23.119650 个 Baseline 标准差，超过三倍要求。540 次真实调用全部通过；最大 NRMS 0.007341078344，最低 Spearman 0.999941807549，最低 top25% 重叠 0.993333333333。

Reference 采用带质量权重的标签条件 farthest-first 支撑压缩及三轮 Voronoi centroid 更新，只求实际使用的跨域标签几何，并复用已计算的每对 batch 成本。它改变经验分布表示与计算图，整个优化面不是只调一个常数。更小支撑失败、较慢的批量标签实现等原记录保留。

评分为 (B−x)/(B−U)，U=0 是非负 elapsed time 的数学下确界，未承诺可实现，也不剪裁分数。公开 B 使用上述实测值。隐藏 verifier 独立 Baseline 五 seed 均值为 0.968649282300 秒，标准差 0.146887374325；隐藏规模不同，不能用公开 B 代替。隐藏校准只执行 canonical Baseline，没有比较 Reference/优化候选，也未向方法选择提供反馈。

## Baseline 健康性与结论边界

训练充分性、optimizer updates、best/last checkpoint 和训练重载复评分不适用：任务是非训练数值推理，相同外部 encoder 缓存共同使用。未知的 encoder 训练历史不能写成已证明充分。canonical 检查 batch 边缘收敛与有限输出，正常完成所有正式调用并通过预注册保真门槛。没有把异常退出或坏权重当作正式 B 的证据。

Baseline 是修复后官方 practical 路径的透明起点。full 标签几何包含最终算子未使用的项，是官方通用路径的可见计算冗余；不能宣称 canonical 是当前最快实现或效率 SOTA。评分锚点的适用范围限于这一明确数值算子与固定资源下的优化。早期 NLL/kNN 检测优势已经披露，未按年份或推测作者动机评判对照。

## 当前运行边界与版本证据

最终 Actor 镜像为 guard-v5，SHA-256 为 `e023560824f59aca7df8ee55168b9c4286d05072802cf5b8588f4f21f2a8761f`。共同入口在标准容器启动时启动受保护 Dev 服务，确认队列就绪后降为 UID1000。共同 guard 又堵住了实测可接受的 NumPy 间接 os/sys 访问，并在公开服务与独立 verifier 检查 method.py/solve.sh 以外的提交资产。九项已知间接访问负向探针均被拒绝，66 份此前受保护测量的源码仍可接受；真实容器 extra-file 测试返回 HARD_GATE。此证据不宣称穷尽操作系统攻击面。

这些修复不属于算法收益。除 guard 外，整个 evaluator 的 Python AST 与此前版本相同；输入、targets、worker、方法计时、seeds、质量门和 B/R/U 均未改变。`runtime_repairs/current_binding.json` 给出当前文件哈希及变更范围。`boot_transport/equivalence.json` 和旧 `runtime_view/` 长跑网络记录只说明各自历史版本，当前 UID、能力、资源和路径视图见 `runtime_repairs/identity.json` 与 `agent_view.json`。旧模型 Actor 的方法必须通过当前 guard 才能参与最终选优。
